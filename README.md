## Overview

Porting Kit is a macOS app that wraps Wine in pre-configured installation bottles, giving Mac users a curated library of 1000+ game recipes that install and launch Windows titles without any manual Wine configuration. It integrates Steam, GOG, and disc-based game installs and uses DXVK to translate DirectX 9/10/11 calls to Metal, dramatically extending compatibility across older and newer Windows games on Apple Silicon and Intel Macs.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Porting Kit** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **1000+ Game Recipes** | Pre-configured Wine bottles for 1000+ Windows games requiring zero manual setup |
| **DXVK Translation** | DirectX 9/10/11 to Metal translation via DXVK for broad GPU compatibility |
| **Multiple Sources** | Install games from GOG, Steam, disc images, or downloaded executables |
| **Apple Silicon Ready** | Native recipes for M1/M2/M3/M4 Macs alongside Intel builds |
